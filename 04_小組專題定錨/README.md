## Challenge Boundary（本課程共同邊界）

本階段所有專題定錨必須符合 `docs/challenge-boundary.md` 所定義之 6 邊界，不得偏離：

- **問題邊界**：L2 資訊流與交接層之承接／整合／確認／延續失效（遺漏或重複確認）
- **角色邊界**：照服人員 ↔ 護理人員（跨角色）
- **情境邊界**：住民重要變化後「照服觀察回報 → 護理整合處置 → 下一班交接」全鏈
- **需求邊界**：使重要照護資訊被即時、清楚地承接、整合、確認與延續
- **限制邊界**：工作節奏緊湊、跨班頻繁、資訊分散於不同媒介（不得移除）
- **介入邊界**：僅限 L2，設計並驗證「跨角色照護資訊承接與確認機制」

> 詳細定義與「需確認」標示請見 [docs/challenge-boundary.md](../docs/challenge-boundary.md)
