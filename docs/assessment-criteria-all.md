# 各 Milestone 推導評量向度

> 依 `docs/learning-evidence-map.md` M1–M4 證據與 `docs/competency-co-objectives.md` CO1–CO8，對應 `docs/competency-evidence-matrix.md`。每 Milestone 推導 4–5 向度，用於形成性評量與 Gate。

## M1 W05｜場域理解與證據建構（P1→P2）

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜場域證據完整性 | 觀察／訪談／媒介紀錄是否具體、可追溯且多源 |
| B｜角色與情境理解 | 是否辨識照服與護理的職責差異及「何謂重要變化」的不同認知 |
| C｜資訊盤點與標示 | 媒介與交接形式是否被完整盤點，承接點與斷點是否被標示於 As-Is 流程 |
| D｜事實與臆測區分 | 是否區分已觀察事實與個人推測，避免將印象當證據 |
| E｜團隊協作紀錄 | 分工與協作過程是否留下可追溯紀錄 |

*對應 CO：CO1、CO2、CO5、CO7*

## M2 W09｜問題診斷與核心問題（P3→P4）G1 Gate

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜場域證據運用 | 問題分析是否建立在具體、可追溯的訪談／觀察及場域證據上 |
| B｜問題現象辨識 | 是否能辨識角色工作痛點、流程卡點及資訊斷點，而非抽象標籤 |
| C｜跨面向關聯分析 | 是否能建立 Journey、Process、Information Flow 及跨角色問題之間有證據支持的關係 |
| D｜核心問題形成 | 是否能從多項現象與關係形成具系統性、重要性且值得介入的 Core Problem |
| E｜證據與推論邊界 | 是否能區分已知證據、合理推論與待驗證假設，避免將推測視為事實 |

*對應 CO：CO1、CO4、CO6、CO8（Rubric V0 詳見 `docs/rubric-m2-v0.md`）*

## M3 W13｜機制原型（P5→P6）G2 Gate

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜限制下設計貼合度 | 機制是否在「節奏緊湊／跨班頻繁／資訊分散」限制下設計，而非移除限制 |
| B｜跨角色承接完整性 | 是否明確定義誰／何時／對何資訊／如何確認／如何記錄的跨角色承接確認 |
| C｜原型可操作性 | Prototype（流程卡／表單／步驟）是否可被他人直接執行，非紙上概念 |
| D｜試跑與迭代依據 | 試跑是否記錄耗時與操作性，迭代是否依據回饋而非臆測 |
| E｜邊界一致性 | 機制是否對應 M2 定錨的斷點與 4 檢核，未偏離 L2 |

*對應 CO：CO3、B4、CO6、CO8*

## M4 W16｜場域驗證與價值整合（P7→P8）

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜驗證設計適切性 | 驗證是否涵蓋常態與尖峰切片，並設計「下一班已承接／需延續」的證據蒐集方式 |
| B｜證據蒐集與比對 | 是否蒐集驗證前後比對證據，證明遺漏／重複是否改善 |
| C｜限制正視與評估 | 是否檢核三限制仍被正視而非被移除，評估未解問題與副作用 |
| D｜移轉與可持續性 | 移轉文件是否讓場域人員可持續執行，操作指引是否清晰可傳承 |
| E｜價值論證與反思 | 是否整合 P1–P7 證據鏈說明機制價值與侷限，提出後續建議而非僅宣告成功 |

*對應 CO：CO1、CO3、CO7、CO8*

---

> 使用：M1 為 Checkpoint（形成性），M2 與 M3 為 Gate（通過性），M4 為終檢（總結性）；每向度檢視對應 Learning Evidence 是否留下可觀察產出。
