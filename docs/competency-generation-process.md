# 能力生成歷程（不以週次計，以真實任務與轉變計）

> 依 Challenge：L2 照服↔護理、住民重要變化後「觀察回報→護理整合處置→下一班交接」｜來源 `docs/key-tasks-breakdown.md` T1–T7、`docs/competency-co-objectives.md` CO1–CO8

| 能力生成階段 | 學生主要學習任務 | 關鍵能力轉變 | 對應能力目標 |
|---|---|---|---|
| **P1｜場域與角色理解** | 進入照護場域，跟隨照服與護理各至少 2 班，不干擾觀察；訪談兩角色對「何謂重要變化／已承接」的日常理解；盤點實際媒介與交接形式，繪製 As-Is 草圖 | 從「想像照護」到**能同理兩角色的視角差異**：辨識照服現場語言與護理整合需求的落差，理解限制（緊湊／頻繁／分散）為不可移除前提 | CO2 關愛生命、CO5 照顧服務、CO6 溝通協調 *（基礎同理與識讀）* |
| **P2｜場域證據建構** | 以結構化記錄蒐集觀察、訪談、媒介紀錄；進行多來源比對，標定資訊在何時、何媒介、何角色間出現不一致或重複；整理為可追溯的證據包 | 從「聽故事」到**能蒐集並整合證據**：將零散口述轉為可驗證的資料，能區分事實與臆測 | CO1 科學實證（蒐集整合）、CO5 照顧服務、CO7 團隊合作（分工蒐集） |
| **P3｜問題診斷** | 比對 P2 證據，分析遺漏／重複確認的時點與成因（斷點在 P1–P4 哪一段），判斷媒介分散與節奏如何放大問題；收斂至 PS-A/B/C/D 的具體斷點假設 | 從「描述現象」到**能分析並判斷問題**：以證據形成可檢驗的診斷假設，而非歸因於個人 | CO1 科學實證（分析判斷）、CO4 人本照顧（個別差異）、CO6 溝通協調 |
| **P4｜核心問題與介入定錨** | 與場域人員共識「何謂即時／清楚／已確認」，定義介入邊界（L2 可做／不可做），將診斷轉為機制必須滿足的 4 檢核（承接／整合／確認／延續），完成定錨 Gate | 從「發現問題」到**能轉化需求並定錨介入**：將場域語言轉為可設計的規格，能說「不做什麼」 | CO2 關愛生命、CO6 溝通協調、CO8 事業管理（邊界與可持續）、CO4 人本照顧 |
| **P5｜跨域方案設計** | 依定錨的 Space（A/B/C/D）設計承接確認機制與操作流（誰／何時／對何資訊／如何確認／如何記錄），納入共同情境（媒介分散）與情境負荷（尖峰切片），撰寫操作指引草案 | 從「界定需求」到**能整合限制進行設計**：在不可移除的限制下形成可行機制，而非理想化流程 | CO3 終身學習（設計反思）、CO6 溝通協調、CO8 事業管理、CO4 人本照顧 |
| **P6｜原型化** | 將機制轉為可操作的 Prototype（流程卡／表單／協作步驟等，非指特定 App／AI），在低風險時段試跑，記錄耗時與操作性 | 從「紙上設計」到**能轉化為可操作的原型**：讓機制可被他人執行與觀察 | CO3 終身學習、B4 原型化、CO5 照顧服務、CO7 團隊合作 |
| **P7｜場域驗證與迭代** | 在真實「變化後到下一班交接」情境中驗證（含常態與尖峰），蒐集下一班是否已承接／需延續的證據，評估對遺漏／重複的改善，依回饋修正迭代 1–2 輪 | 從「做出來」到**能蒐集證據、評估並修正**：以場域證據判斷有效性，能放棄無效設計 | CO1 科學實證（評估）、CO3 終身學習（修正）、CO6/C07 協作、CO8 管理（可持續） |
| **P8｜成果整合與價值說明** | 整合 P1–P7 證據鏈，形成結案報告與移轉文件；向場域與同儕說明機制價值、未解問題與後續建議，完成反思 | 從「完成驗證」到**能整合證據說明價值並移轉**：將過程轉為可傳承的知識，能論證為何機制值得被持續使用 | CO3 終身學習、CO7 團隊合作、CO8 事業管理、CO2/C04 價值論述 |

> **轉變邏輯**：P1 理解→P2 建構證據→P3 診斷判斷→P4 定錨轉化→P5 設計→P6 原型→P7 驗證評估→P8 整合移轉。每階段皆留下 Learning Evidence（流程圖／比對表／診斷報告／規格清單／Prototype／驗證報告／移轉文件），對應 CO1–CO8 可評量。
