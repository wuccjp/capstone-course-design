# Challenge Boundary — Capstone 課程挑戰邊界整理

> 依據已確認之 Capstone Challenge Input Card 原文整理，未新增假設或解方。
> 原文：「請設計並驗證一項【跨角色照護資訊承接與確認機制】，在【L2 資訊流與交接層】，協助【照服人員與護理人員】於【住民重要變化出現後，從照服現場觀察與回報、護理整合與處置，到下一班交接的過程】中，即使面對【工作節奏緊湊、跨班交接頻繁、資訊分散於不同媒介，導致重要資訊容易遺漏或重複確認】的限制，仍能【使重要照護資訊被即時、清楚地承接、整合、確認與延續】。」

## 1. 問題邊界

- **範圍內**：L2 資訊流與交接層中，跨角色照護資訊「承接、整合、確認、延續」失效所衍生之問題，具體表現為「重要資訊容易遺漏或重複確認」。
- **範圍外**：非 L2 層之問題不在範圍（資料僅限定 L2，未提及之其他層面不得自行納入）。
- **需確認**：除「遺漏／重複確認」外，是否還有其他資訊流問題屬本挑戰範圍？資料未列舉，不得自行補充，標示為需確認。

## 2. 角色邊界

- **範圍內**：照服人員、護理人員 — 二者間的跨角色協作與資訊交接。
- **範圍外**：資料未提及之家屬、醫師、行政、住民本人等角色，不在本次角色邊界內。
- **需確認**：照服／護理內部的班別差異（日班／夜班／下一班）屬「跨班」情境，已涵蓋於情境邊界；但角色定義是否包含「所有班別之同職種人員」或僅特定班別，資料未細分，標示為需確認。

## 3. 情境邊界

- **範圍內**：住民「重要變化出現後」，完整流程涵蓋：
  1. 照服現場觀察與回報 →
  2. 護理整合與處置 →
  3. 到下一班交接的過程。
- **範圍外**：非「住民重要變化出現後」之日常例行照護、或未涵蓋「觀察—回報—整合—處置—交接」全鏈之片段情境，不在範圍。
- **需確認**：「住民重要變化」之具體定義與判定標準、「下一班」是否包含跨日／跨單位交接，資料未明確，標示為需確認。

## 4. 需求邊界

- **範圍內**：使「重要照護資訊」被「即時、清楚地承接、整合、確認與延續」。
- **範圍外**：資料未提及之其他需求（如提升照護技術、降低人力工時、改善硬體設備等）不在需求邊界內。
- **需確認**：「即時、清楚」的具體衡量標準與驗證方式，資料未定義，標示為需確認（僅能依原文需求描述為準，不得自行設定指標）。

## 5. 限制邊界

- **範圍內（必須正視且不得移除的前提）**：
  - 工作節奏緊湊
  - 跨班交接頻繁
  - 資訊分散於不同媒介
  - 上述限制導致「重要資訊容易遺漏或重複確認」
- **範圍外**：資料未提及之其他限制（如法規、預算、人力編制等）不得自行納入限制邊界。
- **需確認**：「不同媒介」具體指哪些媒介，資料未列舉，標示為需確認。

## 6. 介入邊界

- **範圍內**：
  - 層級：僅限 L2 資訊流與交接層
  - 對象：協助「照服人員與護理人員」之「跨角色」機制
  - 任務：設計並驗證一項「照護資訊承接與確認機制」
  - 驗證要求：必須包含驗證環節
- **範圍外**：單一角色內部優化、非 L2 層之介入（如 L1 現場照護操作、L3 組織管理系統）、非「承接與確認」性質之介入，不在範圍。
- **需確認**：「驗證」之場域、對象與方法，資料僅要求「驗證」但未明確細節，標示為需確認。

## 本課程學生專題共同不能偏離的探索邊界是什麼？

**本課程所有專題皆須聚焦於「L2 資訊流與交接層」，在「住民重要變化出現後自照服觀察回報、護理整合處置到下一班交接」的特定情境中，針對「照服人員與護理人員」之跨角色協作，在「工作節奏緊湊、跨班頻繁、資訊分散易遺漏／重複確認」的限制下，探索如何使「重要照護資訊被即時、清楚地承接、整合、確認與延續」的機制，不得偏離至其他層級、其他角色、其他情境或自行新增問題與解方。**
