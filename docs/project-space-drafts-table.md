# Project Space Draft — 對照表

> 依據 `docs/challenge-boundary.md` 與 `docs/project-space.md`，限 L2 照服↔護理、住民重要變化後「觀察回報→護理整合處置→下一班交接」｜未提解方、未形成最終題目、保留進場驗證空間

| Project Space Draft | 涉及的主要探索內容 | 對應的 Challenge Boundary | 來源 Lens |
|---|---|---|---|
| **PS-1 現場觀察回報的訊息轉譯與完整性** | 照服現場觀察如何被描述與回報、回報內容的完整度／時效與術語落差如何影響護理整合；聚焦觀察→回報→整合的斷點。*需場域驗證*：實際回報語句與判定標準一致性 | 問題邊界（L2 承接／整合失效）<br>角色邊界（照服↔護理）<br>情境邊界（重要變化後觀察回報段）<br>資訊邊界（重要資訊定義）<br>限制邊界（節奏緊湊、資訊分散）<br>需求邊界（即時、清楚地承接） | **Role + Process + Information**（主）<br>Scenario 輔助 |
| **PS-2 護理整合與處置的資訊承接** | 護理如何彙整多來源多媒介片段資訊並形成處置，處置依據與後續指示如何被照服承接與確認；聚焦整合→處置的承接迴路。*需場域驗證*：彙整方式與確認路徑 | 問題邊界（整合／確認失效）<br>角色邊界（照服↔護理跨角色）<br>過程邊界（整合→處置）<br>資訊邊界（分散媒介一致性）<br>協調邊界（確認機制）<br>介入邊界（L2 跨角色機制） | **Process + Coordination + Information** |
| **PS-3 跨班交接的確認與延續** | 當班處置後到下一班的交接中，交班者與接班者如何確認「已承接／需延續」事項；確認不一致、重複確認或遺漏的時點與成因。*需場域驗證*：交接形式與確認樣態 | 情境邊界（到下一班交接全鏈）<br>角色邊界（跨班跨角色）<br>問題邊界（遺漏／重複確認）<br>需求邊界（確認與延續）<br>限制邊界（跨班頻繁） | **Coordination + Scenario + Process** |
| **PS-4 分散媒介下的資訊一致性** | 重要照護資訊分散於不同媒介時的同步與一致性；同一資訊在多媒介間差異、更新時機與可信度對承接延續的影響。*需場域驗證*：媒介種類與同步頻率 | 限制邊界（資訊分散於不同媒介）<br>資訊邊界（媒介一致性）<br>問題邊界（遺漏／重複確認）<br>需求邊界（清楚、延續） | **Information**（主）<br>Process + Scenario 輔助 |
| **PS-5 緊湊節奏與多重變化下的優先與協調** | 工作節奏緊湊、同時段多位住民變化或人力緊繃時，照服與護理如何排序與分配注意力；追問／複誦等協調行為被省略的情境與後果。*需場域驗證*：緊湊樣態與省略發生率 | 限制邊界（節奏緊湊、交接頻繁）<br>情境邊界（多重變化、班別差異）<br>協調邊界（協調行為）<br>需求邊界（即時性受挑戰） | **Scenario + Coordination**（主）<br>Role 輔助 |
| **PS-6 備選：追蹤與回饋迴路的延續性** | 下一班承接後，後續追蹤與回饋如何回到原班形成延續迴路；延續事項追蹤點與結案判斷如何被確認。*需場域驗證*：迴路是否存在與發起者 | 需求邊界（延續）<br>過程邊界（處置→交接→延續）<br>協調邊界（責任延續）<br>情境邊界（跨班延續） | **Coordination + Process** |

> 備註：PS-1～PS-5 為核心 5 組，已涵蓋五視角（R/S/P/I/C）全部問題空間；PS-6 視教學能量取捨。皆保留學生於 01 問題探索～04 小組專題定錨階段進場診斷與驗證空間，未提 App／平台／AI／Dashboard／Agent 等解方。
