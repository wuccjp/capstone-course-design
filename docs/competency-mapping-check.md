# 能力對映與檢核 — Challenge 推導 vs 系所培育目標

> 檢核：由 Challenge 推導的 8 項能力目標是否與系所人才培育目標一致？是否存在缺口或不必要能力。來源 `docs/challenge-boundary.md:57` & `docs/competency-co-objectives.md:1`。

## 檢核結論

- **是否一致？** 是。8 項 PO 皆可在 Challenge 中找到明確對應，無一是由課程外加；Challenge 的 L2 跨角色資訊承接情境同時涵蓋人文（CO2/CO4）、專業（CO1/CO5）、協作（CO6/CO7）、系統（CO3/CO8）四層，與智慧雨林「批判／人文／自主／溝通／合作／實踐」核心能力亦對應。
- **是否存在不必要的能力？** 否。8 項皆為完成 T1–T7 所需：移除任一項將導致機制無法被證據支持（缺 CO1）、無法尊重住民（缺 CO2/CO4）、無法迭代（缺 CO3）、無法執行（缺 CO5）、無法跨角色運作（缺 CO6/CO7）或無法延續（缺 CO8）。
- **是否存在缺口？** 無明顯缺口；若需強化，僅建議在評量時加重 **CO1 科學實證** 與 **CO6 溝通協調** 的權重，因 Challenge 核心為「遺漏／重複確認」的證據診斷與跨角色確認，二者在驗證報告與確認紀錄中最易留下差異化證據。
- **是否皆可評量？** 是。8 項能力目標皆以行動動詞撰寫並綁定具體產出（見 `docs/competency-co-objectives.md:7`），皆可透過文件與場域紀錄直接評量，非「了解／熟悉」類抽象描述。

> 操作建議：04 小組專題定錨時以本表作為 PO 對應檢核；07 場域驗證以 CO1/CO6 產出作為主要評量錨點，其餘 CO 以歷程檔案檢核。
