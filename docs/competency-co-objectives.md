# B. 生成能力轉能力目標（校訂 8 能力對應版）

> 依校訂能力：科學實證、關愛生命、終身學習、人本照顧、照顧服務、溝通協調、團隊合作、事業管理，對應 Challenge：L2 照服↔護理、住民重要變化後「觀察回報→護理整合處置→下一班交接」。避免「了解／認識／熟悉／具備」，使用可留下 Learning Evidence 的行動動詞：分析、辨識、形成、判斷、整合、轉化、蒐集、評估、修正。來源 `docs/challenge-boundary.md:57`。

| 編號 | 生成能力 | 能力目標（一句話，含行動動詞、依據、產出） |
|---|---|---|
| CO1 | 科學實證 | 能**依據**場域觀察、訪談與媒介比對紀錄，**分析**「觀察→回報→整合→交接」鏈中遺漏／重複確認的時點，**判斷**可介入的斷點假設，**產出**斷點分析報告與一致性比對表。 |
| CO2 | 關愛生命 | 能**辨識**住民重要變化對生命安全與尊嚴的影響，**轉化**為照護資訊必須被承接的優先順序，**評估**資訊延誤的風險，**產出**風險標定紀錄與共識的承接標準。 |
| CO3 | 終身學習 | 能**蒐集**試跑與場域驗證回饋，**評估**自身機制缺口並**修正**迭代，**形成**個人學習調整紀錄，**產出**迭代對照表與反思日誌。 |
| CO4 | 人本照顧 | 能**整合**住民個別差異與以人為本的照顧需求，**形成**尊重個體的資訊承接方式，**產出**以住民為中心的資訊承接指引片段。 |
| CO5 | 照顧服務 | 能**依據**照服現場觀察紀錄，**辨識**並**形成**完整的回報內容（何時／何事／何媒介），**產出**標準化的觀察回報紀錄表。 |
| CO6 | 溝通協調 | 能**轉化**照服與護理的語言差異為共同確認語句，**整合**並**形成**跨角色承接與確認流程，**產出**經雙方簽認的確認流程與確認紀錄。 |
| CO7 | 團隊合作 | 能**整合**跨角色、跨班分工，**蒐集**協作回饋並**判斷**責任歸屬，**產出**分工與交接責任對照表及協作紀錄。 |
| CO8 | 事業管理 | 能**形成**機制在「節奏緊湊／跨班頻繁／資訊分散」限制下的運作與追蹤管理方式，**評估**驗證成效與可持續性，**產出**管理檢核表與場域移轉文件。 |

> **對應**：CO1→B2、B5 科學證據；CO2→B1 價值轉譯；CO3→B4/B6 學習迭代；CO4→B1 人本轉譯；CO5→B1/B3 照顧實務；CO6→B1/B3 溝通；CO7→B6 團隊；CO8→B3/B5 管理。皆可觀察、可學習（對應 T1–T7）、可評量（有產出證據）。
