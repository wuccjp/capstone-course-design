# 各 Milestone 推導評量向度 Rubrics（依 CO × Evidence）

> 每 Milestone 皆依其 Learning Evidence 推導 5 向度 Assessment Criteria，再展開 R1–R4 Rubric。已建檔：`docs/rubric-m1-v0.md`、`docs/rubric-m2-v0.md`、`docs/rubric-m3-v0.md`、`docs/rubric-m4-v0.md`

## M1 W05｜場域理解與證據建構（P1→P2）

### Assessment Criteria（CO1/CO2/CO5/CO7 × 證據包）

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜場域證據運用 | 問題描述是否建立在具體、可追溯的訪談、觀察及媒介盤點證據上 |
| B｜角色工作痛點辨識 | 是否能辨識照服與護理對重要資訊的認知差異與現場痛點，而非抽象描述 |
| C｜紀錄完整性 | 是否能以人／時／事／媒介／中斷點完整記錄，使他人可追溯 |
| D｜流程與媒介盤點 | 是否能繪製 As-Is 流程並盤點媒介一致性落差 |
| E｜倫理與協作邊界 | 是否能區分可觀察事實與待驗證臆測，並遵守倫理與分工 |

### Rubric（摘要，詳見 `docs/rubric-m1-v0.md:4`）

| 向度 | R1 待加強 | R2 基本 | R3 良好 | R4 優異 |
|---|---|---|---|---|
| A | 無可追溯證據 | 1 類部分可追溯 | 2–3 類多數可追溯 | 3 類三角驗證 |
| B | 單一視角 | 能描述職責但差異模糊 | 具體辨識落差有原話佐證 | 同理說明落差影響並獲認可 |
| C | 缺漏無標註 | 有時間對象但缺媒介 | 完整 5 要素多數可追溯 | 完整且可被他人複核 |
| D | 無流程或清單 | 草圖缺承接點 | 圖標承接點與斷點，能比對落差 | 精準對照並指出落差位點 |
| E | 未守倫理或分工亂 | 基本倫理但紀錄不全 | 守保密且分工紀錄完整 | 主動反思並協調分歧 |

## M2 W09｜問題診斷與核心問題（P3→P4，G1）

### Assessment Criteria（CO2 × Evidence）

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜場域證據運用 | 問題分析是否建立在具體、可追溯的訪談、觀察及場域證據上 |
| B｜問題現象辨識 | 是否能辨識角色工作痛點、流程卡點及資訊斷點，而非停留在抽象問題標籤 |
| C｜跨面向關聯分析 | 是否能建立 Journey、Process、Information Flow 及跨角色問題之間有證據支持的關係 |
| D｜核心問題形成 | 是否能從多項現象與關係形成具系統性、重要性且值得介入的 Core Problem |
| E｜證據與推論邊界 | 是否能區分已知證據、合理推論與待驗證假設，避免將推測視為事實 |

### Rubric（詳見 `docs/rubric-m2-v0.md:12`）

| 向度 | R1 待加強 | R2 基本 | R3 良好 | R4 優異 |
|---|---|---|---|---|
| A | 無或不可追溯，臆測 | 1 類部分可追溯 | 2–3 類多數可追溯 | 3 類三角驗證並標侷限 |
| B | 抽象標籤 | 現象模糊未分類 | 具體辨識≥2 類有事例 | 精準定位節點並說明影響 |
| C | 孤立 | 單一面向 | ≥2 面向有據關聯 | 4 面向網路並駁替代解釋 |
| D | 無或過泛 | 系統性不足 | 具三性對應 PS/L2 | 兼具三性且說明槓桿並獲共識 |
| E | 推測當事實 | 部分混淆 | 明確區分並標待驗證 | 完整邊界並說明驗證方法 |

## M3 W13｜機制原型（P5→P6，G2）

### Assessment Criteria（CO3/B4/CO6/CO8 × Prototype）

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜機制對應性 | 機制是否對應 M2 診斷的斷點與 4 檢核（承接／整合／確認／延續），且位於 L2 |
| B｜限制下可行性 | 是否在節奏緊湊、跨班頻繁、資訊分散下可被執行的機制 |
| C｜可操作性與清晰度 | 操作流是否清晰（誰／何時／對何資訊／如何確認／如何記錄）可被他人執行 |
| D｜原型完整性 | Prototype 是否完整涵蓋主情境與共同情境，可被試跑 |
| E｜試跑與迭代證據 | 是否以試跑回饋評估操作性並修正迭代，留下決策依據 |

### Rubric（詳見 `docs/rubric-m3-v0.md:4`）

| 向度 | R1 | R2 | R3 | R4 |
|---|---|---|---|---|
| A | 脫節未對應 | 部分對應有偏離 | 完全對應 L2 與 4 檢核 | 精準槓桿並獲共識 |
| B | 理想化未考慮限制 | 提及未落實 | 三限制下可執行有佐證 | 常態與尖峰皆可行可量化 |
| C | 要素缺漏模糊 | 有要素但不清 | 5 要素俱全可執行 | 可列印一次通過誤差低 |
| D | 無或僅概念 | 缺指引或共同情境 | 完整涵蓋主與共同情境 | 兼具常尖峰版型可移轉 |
| E | 無試跑 | 1 次簡略無修正 | 1 輪可追溯修正 | 2 輪數據化完整決策 |

## M4 W16｜場域驗證與價值整合（P7→P8）

### Assessment Criteria（CO1/CO3/CO7/CO8 × 驗證報告）

| 評量向度 | 主要判斷內容 |
|---|---|
| A｜驗證設計嚴謹性 | 驗證計畫是否含常態與尖峰切片及「下一班已承接」證據設計，可被複現 |
| B｜證據蒐集與前後比對 | 是否蒐集簽收／確認紀錄進行前後比對，量化遺漏／重複變化 |
| C｜限制正視與改善評估 | 是否評估機制在三限制下是否被正視並評估改善與未解問題 |
| D｜移轉與可持續性 | 移轉文件是否可被場域持續使用並獲回饋 |
| E｜反思與價值論證 | 是否整合 P1–P7 證據鏈說明價值、未解問題與後續建議 |

### Rubric（詳見 `docs/rubric-m4-v0.md:4`）

| 向度 | R1 | R2 | R3 | R4 |
|---|---|---|---|---|
| A | 無計畫單次 | 有計畫但缺切片 | 完整兩切片可複現 | 嚴謹含對照並說明侷限 |
| B | 無比對自述 | 單薄缺簽收 | 有簽收前後比對可量化 | 多源三角並標未解 |
| C | 移除限制未檢核 | 提及模糊 | 評估正視並說明未改善 | 論證可持續並提再優化 |
| D | 無或不可用 | 有但操作不足 | 可持續獲回饋 | 獲簽收採納有追蹤 |
| E | 無反思空泛 | 有但缺證據鏈 | 整合證據鏈說明價值 | 論證值得持續並提研究問題 |
