# Project Space 檢視與整併 — 四項判準

> 依據 `docs/challenge-boundary.md` 與 `docs/project-space-drafts-table.md` PS-1~PS-6，對應附件「四項判準」與「逐項檢視結果」格式

## 四項判準（Project Space Framing Criteria）

| 判準 | 核心問題 | 判斷重點 |
|---|---|---|
| **Challenge Alignment** | 是否直接回應共同 Challenge？ | 能否追溯至 Core Problem、Needs、Constraints 或 Intervention Boundary |
| **Distinctiveness** | 與其他 Project Space 是否具有足夠差異？ | 是否只是另一 PS 的子項或換句話說 |
| **Exploration Value** | 是否值得學生重新進場探索與診斷？ | 是否仍存在需要透過訪談、觀察與證據才能理解的問題 |
| **Project Potential** | 是否具有形成學生 Capstone Project 的空間？ | 是否能從探索 → 診斷 → 介入 → 設計 → Prototype → Validation |

## 整併邏輯（關聯／重疊／邊界）

- **重疊**：PS-4 與 PS-1/PS-2/PS-3 在「資訊分散」上高度重疊；PS-6 為 PS-3 子項。
- **邊界**：PS-4、PS-6 若獨立，易偏離「到下一班為止」與「L2 跨角色」錨點。
- **探索價值**：5 個 Draft 皆高探索價值，但 PS-4 獨立時探索路徑會分散，轉為共同情境反而提升各 PS 深度。
- **整併決策**：保留流程上互補的 PS-1、PS-2、PS-3（＋PS-6）、PS-5 四組，將 PS-4 橫切化。

## 界定後適合本課程的專題探索空間（4 組）

> 皆位於 Challenge Boundary 內，未提解方，未形成最終題目，保留 01 問題探索→04 定錨空間

### Space A｜A1 前端轉譯：現場觀察回報的訊息轉譯與完整性（原 PS-1 保留）

- **核心探索**：照服現場觀察如何被描述、回報，完整度與術語落差如何影響護理整合
- **涉及主要內容**：R1/R2/I1/I4/P1/P2
- **對應 Boundary**：問題、角色、情境（觀察回報段）、資訊、限制（緊湊／分散）、需求（即時清楚承接）
- **來源 Lens**：Role + Process + Information
- **共同情境**：需在「資訊分散」與「緊湊節奏」共同情境下驗證

### Space B｜B1 中段整合：護理整合與處置的資訊承接（原 PS-2 保留）

- **核心探索**：護理如何彙整多來源多媒介片段資訊並形成處置，處置依據如何被照服承接確認
- **涉及主要內容**：P3/R3/I3/C1
- **對應 Boundary**：問題（整合確認失效）、角色（跨角色）、過程（整合→處置）、協調、介入（L2 機制）
- **來源 Lens**：Process + Coordination + Information
- **共同情境**：同上，媒介一致性為必檢項

### Space C｜C1 後段延續：跨班交接的確認、延續與追蹤（PS-3 ＋ PS-6 整併）

- **核心探索**：當班處置後到下一班如何確認已承接／需延續，認知不一致與遺漏／重複確認的時點成因；延伸追蹤回饋是否形成迴路
- **涉及主要內容**：P4/S4/C2/C5/R4/S3（＋ PS-6 的追蹤迴路探針）
- **對應 Boundary**：情境（到下一班全鏈）、角色（跨班跨角色）、問題（遺漏／重複確認）、需求（確認與延續）、限制（跨班頻繁）
- **來源 Lens**：Coordination + Scenario + Process
- **界定說明**：PS-6 不獨立，原「回饋迴路」改為本 Space 的選修深究題，僅在場域證實存在迴路時才展開

### Space D｜D1 情境負荷：緊湊節奏與多重變化下的優先與協調（原 PS-5 保留）

- **核心探索**：緊湊節奏、同時多位住民變化或人力緊繃時，如何排序、分配注意力，協調行為（追問／複誦等）被省略的後果
- **涉及主要內容**：S1/S2/R5/C3/C4
- **對應 Boundary**：限制（節奏緊湊／交接頻繁）、情境（多重變化／班別差異）、協調、需求（即時性）
- **來源 Lens**：Scenario + Coordination（主）、Role 輔助
- **共同情境**：與 A/B/C 正交，學生可選「常態流程」或「尖峰情境」作為切入情境

### 跨 Space 共同情境（原 PS-4 轉化）

- **資訊分散於不同媒介**：不獨立立題，所有 Space（A/B/C/D）在場域驗證時皆須盤點實際媒介、比對一致性落差與更新時機，作為機制設計的限制條件而非題目本身。

## 檢核（對應四項判準）

- **Alignment**：4 組皆可追溯至 Core Problem／Needs／Constraints／Intervention，未偏離 L2、未擴至他角色或他層
- **Distinctiveness**：A（前端）、B（中段）、C（後段）、D（負荷情境）四段正交，無子項重疊
- **Exploration Value**：每組皆含 2 項以上「需場域驗證」，須訪談觀察才能診斷
- **Project Potential**：每組皆可走完整 Capstone 流程（探索→診斷→介入判斷→定錨→解方設計→Prototype→場域驗證），具備形成專題空間

> 後續建議：01 問題探索讓學生分組認領 A/B/C/D 進場；02 診斷時以本表「共同情境」進行跨組媒介比對；04 定錨以本表「對應 Boundary」作為 Gate 檢查。
