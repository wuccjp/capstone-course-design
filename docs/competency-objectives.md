# 生成能力 → 能力目標（可觀察、可學習、可評量）

> 依 `docs/competency-generative.md` B1–B6 轉化；避免「了解／認識／熟悉／具備」，使用可留下 Learning Evidence 的行動動詞：分析、辨識、形成、判斷、整合、轉化、蒐集、評估、修正。

| 編號 | 生成能力 | 能力目標（一句話，含行動動詞、依據、產出） |
|---|---|---|
| B1 | 跨角色需求轉譯與共識建構 | 能**依據**照服與護理的訪談與觀察紀錄，**辨識**雙方對「重要資訊／已承接」的認知落差，**轉化**並**形成**可檢核的承接標準，**產出**經場域簽認的需求規格清單與 Gate 檢查表。 |
| B2 | 資訊流診斷與斷點分析 | 能**整合**多來源多媒介比對證據，**分析**「觀察→回報→整合→處置→交接」鏈中的遺漏／重複確認時點，**判斷**可介入的斷點假設，**產出**斷點分析報告與一致性比對表。 |
| B3 | 限制下機制設計 | 能**依據** T2 斷點與限制邊界（節奏緊湊／跨班頻繁／資訊分散），**整合**需求並**設計** L2 跨角色承接與確認機制（含誰／何時／對何資訊／如何確認／如何記錄），**產出**機制設計文件與操作流。 |
| B4 | 原型化與迭代 | 能**將**機制**轉化**為可操作的 Prototype，**蒐集**低風險試跑回饋並**評估**操作性，**修正**迭代機制，**產出** Prototype 迭代版本對照表與測試紀錄。 |
| B5 | 場域驗證與證據評估 | 能**形成**場域驗證計畫（含常態與尖峰切片），**蒐集**「下一班已承接／需延續」證據並**評估**機制對遺漏／重複確認的改善，**產出**場域驗證報告與前後比對。 |
| B6 | 協作與反思移轉 | 能**整合**跨角色跨班協作回饋，**評估**機制成效與未解問題，**修正**並**形成**可移轉的操作指引，**產出**移轉文件與反思總結報告。 |

> 每項目標皆可觀察（行為）、可學習（對應 T1–T7 任務）、可評量（有產出證據）；評量時檢視「依據是否來自場域、動詞是否可觀察、產出是否留下證據」。
