# Project Space 探索 — 基於 Challenge Boundary

> 依據 `docs/challenge-boundary.md` 整理，未重新定義 Core Problem，未提出具體解方。
> 原文邊界：L2 資訊流與交接層｜照服人員與護理人員｜住民重要變化後「照服觀察回報→護理整合處置→下一班交接」｜限制：節奏緊湊、跨班頻繁、資訊分散致遺漏／重複確認｜需求：即時、清楚地承接、整合、確認與延續。

---

## 第一部分：五視角問題空間清單

### Lens 1 — Role 角色視角

聚焦「照服人員與護理人員」二角色間的差異與交界面。

| 編號 | 問題空間（待探索／驗證） | 關聯邊界 |
|------|--------------------------|----------|
| R1 | 照服與護理對「何謂重要變化／需回報資訊」的判斷標準是否一致？不一致時如何被承接？ | 角色、情境、問題 |
| R2 | 照服現場觀察的描述方式與護理所需的整合資訊之間是否存在落差（口語、術語、完整度）？ | 角色、資訊、需求 |
| R3 | 護理處置後的決策與後續照護指示，如何被照服人員理解與承接？責任歸屬是否清晰？ | 角色、過程、協調 |
| R4 | 同職種跨班（如照服A班→照服B班、護理A班→護理B班）與跨職種（照服→護理）交接的資訊需求有何不同？ | 角色、限制、情境 |
| R5 | 需場域驗證：兩角色在緊湊節奏下各自的注意力負荷與可投入交接的時間窗為何？ | 角色、限制 |

### Lens 2 — Scenario 情境視角

聚焦「住民重要變化後到下一班交接」的時空與情境變異。

| 編號 | 問題空間 | 關聯邊界 |
|------|----------|----------|
| S1 | 重要變化發生的時機（日班人力充足 vs 夜班／人力緊繃時）對回報與承接的影響 | 情境、限制 |
| S2 | 同時段多位住民出現變化的情境，資訊如何被排序與承接？是否加劇遺漏？ | 情境、限制、問題 |
| S3 | 「下一班交接」的時間跨度與形式（短交班／長交班、口頭／書面）在不同場域的實際樣態 | 情境、限制、資訊 |
| S4 | 從觀察到下一班交接的完整歷程中，哪些時點最容易發生資訊斷點？ | 情境、過程、問題 |
| S5 | 需場域驗證：何謂「重要變化」在不同住民／照護情境中的實際觸發條件？ | 情境 |

### Lens 3 — Process 過程視角

聚焦「觀察→回報→整合→處置→交接」五步流程的銜接。

| 編號 | 問題空間 | 關聯邊界 |
|------|----------|----------|
| P1 | 觀察→回報：現場觀察到發出回報之間的延遲與遺漏點 | 過程、問題、需求（即時） |
| P2 | 回報→整合：護理如何彙整來自不同照服人員／不同媒介的片段資訊？整合時的缺口為何？ | 過程、資訊、問題 |
| P3 | 整合→處置：整合後到形成處置決策的資訊轉譯是否完整？處置依據是否被記錄與傳遞？ | 過程、資訊、協調 |
| P4 | 處置→交接：處置結果與後續追蹤事項如何被打包交班給下一班？延續性如何確保？ | 過程、需求（延續）、問題 |
| P5 | 需場域驗證：各步驟實際耗時、責任交接點與回饋迴路是否存在？ | 過程、限制 |

### Lens 4 — Information 資訊視角

聚焦「重要照護資訊」本身及其媒介特性。

| 編號 | 問題空間 | 關聯邊界 |
|------|----------|----------|
| I1 | 何謂「重要照護資訊」？其內容類型與必要欄位在實務中是否一致？ | 資訊、需求、問題 |
| I2 | 資訊分散於不同媒介的實際樣態為何？同一資訊在多媒介間的一致性如何？ | 資訊、限制 |
| I3 | 資訊的「即時性」與「清楚性」在現場如何被判斷？是否存在重複確認的成因？ | 資訊、需求、問題 |
| I4 | 資訊在傳遞過程中如何被增刪或變形？原始觀察與最終交班資訊的差異為何？ | 資訊、過程 |
| I5 | 需場域驗證：不同媒介的更新時機與可信度在實務中如何被看待？ | 資訊、限制 |

### Lens 5 — Coordination 協調視角

聚焦跨角色、跨班的協調與確認行為。

| 編號 | 問題空間 | 關聯邊界 |
|------|----------|----------|
| C1 | 照服回報後，如何確認護理已「承接」？護理處置後，如何確認照服／下一班已「確認」？ | 協調、需求（承接／確認）、問題（遺漏） |
| C2 | 跨班交接時，交班者與接班者對「已交接完成」的認知是否一致？確認方式為何？ | 協調、情境、問題（重複確認） |
| C3 | 緊湊節奏下，協調行為（追問、複誦、簽收等）是否被省略？省略的後果為何？ | 協調、限制 |
| C4 | 需場域驗證：現有的協調習慣與非正式約定為何？其對延續性的影響為何？ | 協調、限制 |
| C5 | 責任延續：下一班如何知道自己需「延續」哪些事項？延續的追蹤點為何？ | 協調、需求（延續）、過程 |

## 第二部分：關聯整理與分群

將五視角中彼此高度相關的問題空間進行關聯：

- **群 A — 回報與轉譯斷點**：R1、R2、P1、P2、I1、I4
  > 核心關聯：照服觀察如何被描述、回報、整合成護理可用的資訊，涉及角色認知差異、資訊完整性與流程銜接。

- **群 B — 整合與處置的承接**：R3、P3、I3、C1
  > 核心關聯：護理整合與處置後的資訊如何被承接與確認，涉及處置依據的清晰度與確認迴路。

- **群 C — 跨班交接與延續**：R4、S3、S4、P4、C2、C5
  > 核心關聯：從當班到下一班的交接，涉及時間形式、責任延續與確認一致性。

- **群 D — 媒介分散與一致性**：I2、I5、P2、S3
  > 核心關聯：資訊分散於不同媒介所致的不一致與遺漏，跨群影響回報與交接。

- **群 E — 節奏與負荷下的協調**：R5、S1、S2、C3、C4
  > 核心關聯：工作緊湊與頻繁交接對協調行為的擠壓，涉及情境變異與協調省略。

分群邏輯：A+B 處理當班內的跨角色流程，C 處理跨班延續，D 為橫切的資訊媒介限制，E 為橫切的節奏限制。五群彼此正交互補，未脫離 Challenge Boundary。

## 第三部分：Project Space Draft（4–6 個）

> 皆位於 Challenge Boundary 內，保留學生後續進場探索、診斷與定錨空間；不提出具體解方，不形成最終題目。

### PS-1：現場觀察回報的訊息轉譯與完整性

- **主要探索內容**：在住民重要變化後，照服人員的現場觀察如何被描述與回報，護理人員如何接收與理解；回報內容的完整度、時效與術語落差如何影響後續整合。聚焦 P1、P2 與 R1、R2、I1、I4 的交集。學生需進場觀察實際回報語句、記錄樣態，診斷轉譯斷點。
- **對應 Challenge Boundary**：問題／角色／情境／資訊／過程；限制（節奏緊湊、資訊分散）；需求（即時、清楚地承接）。
- **主要來源 Lens**：Role + Process + Information（主）、Scenario 輔助。
- **需場域驗證**：實際回報語句與記錄形式的差異程度、判定標準的一致性。

### PS-2：護理整合與處置的資訊承接

- **主要探索內容**：護理如何彙整來自不同照服／不同媒介的片段資訊並形成處置，處置依據與後續指示如何被照服承接與確認。聚焦 P3、R3、I3、C1。學生需追蹤同一事件從回報到處置的資訊流，診斷整合時的缺口與確認迴路缺失。
- **對應 Challenge Boundary**：問題／角色／資訊／過程／協調；需求（整合、確認）；介入邊界（L2 跨角色承接機制）。
- **主要來源 Lens**：Process + Coordination + Information。
- **需場域驗證**：整合時的實際彙整方式、處置指示的傳遞路徑與確認方式。

### PS-3：跨班交接的確認與延續

- **主要探索內容**：當班處置後到下一班的交接過程中，交班者與接班者如何確認「已承接」與「需延續」事項；確認不一致、重複確認或遺漏的發生時點與成因。聚焦 P4、S4、C2、C5、R4、S3。
- **對應 Challenge Boundary**：情境（到下一班交接）／角色（跨班跨角色）／問題（遺漏／重複確認）／需求（確認與延續）／限制（跨班頻繁）。
- **主要來源 Lens**：Coordination + Scenario + Process。
- **需場域驗證**：下一班交接的實際形式與時間、確認行為的具體樣態。

### PS-4：分散媒介下的資訊一致性

- **主要探索內容**：重要照護資訊分散於不同媒介時的同步與一致性問題；同一資訊在多媒介間的差異、更新時機與可信度如何影響承接與延續。聚焦 I2、I5、P2、S3，與 PS-1～PS-3 橫切相關。
- **對應 Challenge Boundary**：限制（資訊分散於不同媒介）／資訊／問題（遺漏／重複確認）／需求（清楚、延續）。
- **主要來源 Lens**：Information（主）、Process + Scenario 輔助。
- **需場域驗證**：實際使用媒介種類、同步頻率與一致性落差程度。

### PS-5：緊湊節奏與多重變化下的優先與協調

- **主要探索內容**：在工作節奏緊湊、同時段多位住民變化或人力緊繃情境下，照服與護理如何排序、分配注意力與協調；協調行為（追問、複誦等）被省略的情境與後果。聚焦 S1、S2、R5、C3、C4，與 E 群相關。
- **對應 Challenge Boundary**：限制（節奏緊湊、交接頻繁）／情境（多重變化、班別差異）／協調／問題；需求（即時性受挑戰）。
- **主要來源 Lens**：Scenario + Coordination（主）、Role 輔助。
- **需場域驗證**：緊湊時段的實際工作樣態、多重事件並發頻率、協調省略的實際發生率。

### PS-6（備選，視教學能量取捨）：追蹤與回饋迴路的延續性

- **主要探索內容**：下一班承接後，後續追蹤與回饋如何回到原照服／護理以形成延續迴路；延續事項的追蹤點與結案判斷如何被確認。聚焦 C5、P4、S4 的延伸。
- **對應 Challenge Boundary**：需求（延續）／過程（處置→交接→延續）／協調；情境（跨班延續）。
- **主要來源 Lens**：Coordination + Process。
- **需場域驗證**：追蹤迴路在實務中是否存在、由誰發起與結案。

> 註：PS-1～PS-5 為建議核心 5 組，已涵蓋五視角全部問題空間；PS-6 為延伸，教學團隊可依場域能量與學生人數決定是否開放。所有 Space 皆未提出解方，保留學生進場診斷與定錨（對應 02 問題診斷、03 介入判斷、04 小組專題定錨）空間。

## 後續建議（給教師）

- 讓學生以本文件五視角清單為「進場觀察清單」，於 01 問題探索階段各自選 1–2 Lens 進場。
- 於 02 問題診斷階段以分群邏輯（A～E）進行跨組對照，收斂至 PS-1～PS-5 之一再深化。
- 定錨時以「對應 Challenge Boundary」欄位作為 Gate 檢查點，防止偏離至 L1/L3 或單一角色優化。
